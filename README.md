  before it's too late at the Bridgetown summit, and the US lead over China

  18-item ALSO list, and a DATE CHECK box separating what is — and isn't —
  dated 23 November 2026.

## How to run

```sh
python3 draw.py            # regenerates entry.png (needs Pillow)
MAKEFUN_OUTPUT_DIR=out python3 main.py   # validates + copies entry.png to out/
```

`main.py` is stdlib-only: it parses and validates the PNG header itself and
never writes next to the source files, so it also runs from a read-only copy.
